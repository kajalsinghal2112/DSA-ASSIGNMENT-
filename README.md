# DSA Assignment 2

This repository contains C programs for Data Structures and Algorithms (DSA) Assignment 2.

The programs are written in C language to understand the basic concepts of data structures.

## Topics Covered

### 1. Arrays
- Basic array operations
- Insertion and deletion
- Searching and sorting
- Other array-related programs

### 2. Stacks
- Stack implementation
- Push and pop operations
- Stack applications
- Other stack-related programs

### 3. Queues
- Queue implementation
- Insertion and deletion
- Circular queue
- Other queue-related programs

## Language Used
- C Programming

## Purpose
The purpose of this assignment is to practice C programming and understand the working of different data structures.

## How to Run the Programs

1. Download or clone this repository.
2. Open the program in a C compiler.
3. Compile and run the program.
